# Student Task Management System

## Project Purpose

The Student Task Management System is a small browser-based application for managing student academic tasks.

## Current Features

- Displays sample student tasks.
- Allows users to add a new task.
- Requires a task title and description.
- Provides a responsive and readable interface.

## Project Structure

- `index.html` - Main web page.
- `style.css` - Styling and responsive layout.
- `script.js` - Task creation and validation functionality.
- `README.md` - Project documentation.
- `.gitignore` - Files and folders excluded from Git.

## Usage

1. Open `index.html` in a web browser.
2. Enter a task title.
3. Enter a task description.
4. Click **Add Task**.
5. The new task will appear in the task list.
